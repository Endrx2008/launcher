SKORPION OS

MASTER KEY SYSTEM · USAGE GUIDE

Learn how to use Skorpion OS, with the function keys to control your system. Click a card to read more.

Function keys

Master Key

Alt

ALT IS THE MASTER KEY

Open Launcher

Alt + F1

Press the Master Key and F1 together to open the launcher. Press them again to close it.

Open the File Manager

Alt + F2

Press the Master Key and F2 together to open the file manager.

Open Guide

Alt + F3

Press the Master Key and F3 together to open this guide.

Close Window

Alt + F5

Press the Master Key and F5 together to close the active window.

Launch the Web Browser

Alt + F7

Press the Master Key and F7 together to launch Firefox.

Open Terminal

Alt + F10

Press the Master Key and F10 together to open the terminal.

Change Configuration

Alt + F11

Press the Master Key and F11 together to change this configuration.

Other shortcuts

Terminal

Alt + Enter

Another way to open a terminal.

Close Window

Alt + Shift + Q

Another way to close the active window.

App Menu

Alt + D

Quick menu to run any program by name.

Move Focus

Alt + J / K / L / Ò

Or Alt + the arrow keys.

Move Window

Alt + Shift + J / K / L / Ò

Or Alt + Shift + the arrow keys.

Workspaces

Alt + 1 … 0

Switch between 10 desktops.

Fullscreen

Alt + F

Fullscreen on/off for the active window.

Floating Window

Alt + Shift + Space

Detach a window from the grid.

Tabs

Alt + W

Group windows as tabs.

Next Window Right

Alt + H

The next window opens on the right.

Next Window Below

Alt + V

The next window opens below.

Toggle Split

Alt + E

Side by side ↔ stacked.

Resize Mode

Alt + R

Resize the active window with the keyboard.

Reload Configuration

Alt + Shift + C

Apply changes to the configuration.

Log Out

Alt + Shift + E

End the session.

Touchpad Swipe

3 fingers ← →

Switch workspace on a laptop.

App Menu

Alt + D

Quick menu to run any program by name.

Split Horizontally

Alt + H

The next window opens on the right.

Split Vertically

Alt + V

The next window opens below.

Tabbed Layout

Alt + W

Windows as tabs.

Stacked Layout

Alt + S

Windows as a stacked list.

Tiled ↔ Floating Focus

Alt + Space

Jump between tiled and floating windows.

Focus Parent

Alt + A

Select the whole container.

Restart i3

Alt + Shift + R

Restart i3 keeping your windows.

SKAI Manager

Alt + F9

Manage the local AI: models, on / off, remote PC.
